# Application Resources (`src/main/resources`)

## Overview
Classpath resources for the Gymnasion Spring Boot backend, including environment-specific configuration profiles (`application.properties`, `application-dev.properties`, `application-prod.properties`), Flyway PostgreSQL schema migrations, HTML email templates, embedded OpenPDF TrueType fonts (`plus-jakarta-sans`), and branding assets.

## Subdirectories & Boundaries
- [db](./db/README.md) - Database resource root grouping Flyway PostgreSQL schema migration scripts (`./db/migration/README.md`).
