# REST API Controllers (`controller`)

## Overview
REST API controllers exposing endpoints for authentication, user profiles, sport modalities, custom metrics, classes, training routines/sessions, performance correction/auditing, evolution dashboards, PDF performance reports, notifications, immutable profile observations/feedbacks, and Strava OAuth 2.0 integration for both Personal Trainers and Alunos.

## Invariants
- `[AcompanhamentoTreinoController.java:@PreAuthorize("hasRole('PERSONAL_TRAINER')")]` Personal trainer endpoints require `PERSONAL_TRAINER` role across `AcompanhamentoTreinoController`, `CorrecaoDesempenhoController`, `DashboardEvolucaoController`, `MetricaController`, `NotificacaoController`, `PersonalStravaController`, `PersonalTrainerController`, `RelatorioPerformanceController`, `RotinaTreinoController`, and `TurmaController`.
- `[AlunoDashboardEvolucaoController.java:@PreAuthorize("hasRole('ALUNO')")]` Student endpoints require `ALUNO` role across `AlunoDashboardEvolucaoController`, `AlunoNotificacaoController`, `AlunoObservacaoFeedbackController`, `AlunoPerfilController`, `AlunoRelatorioPerformanceController`, `AlunoRotinaController`, and `AlunoStravaController`.
- `[ModalidadeController.java:@PreAuthorize("hasRole('ADMIN')")]` Modality creation, update, activation, and deactivation endpoints require `ADMIN` role while listing and lookup by ID are public.
- `[ObservacaoFeedbackController.java:@PreAuthorize("hasAnyRole('PERSONAL_TRAINER', 'ALUNO')")]` Shared observation/feedback endpoints allow either `PERSONAL_TRAINER` or `ALUNO` roles.
- `[UsuarioPerfilController.java:@PreAuthorize("isAuthenticated()")]` User profile, preferences, and password update endpoints require any authenticated user.
- `[RelatorioPdfResponse.java:of]` PDF report responses enforce `CacheControl.noStore()` for LGPD compliance and set `Content-Type: application/pdf` on the response entity so error responses remain JSON.

## Side Effects
- `[AuthController.java:AuthController]` Delegates user registration, authentication, and invite consumption to `UsuarioService`, `AuthService`, and `PersonalConviteService`.
- `[RotinaTreinoController.java:RotinaTreinoController]` Delegates routine/session lifecycle, execution recording, and validation mutations to `RotinaTreinoService`.
- `[CorrecaoDesempenhoController.java:corrigirRegistro]` Delegates performance corrections and audit log creation to `CorrecaoDesempenhoService`.
- `[AlunoStravaController.java:AlunoStravaController]` Triggers Strava OAuth connection, disconnection, and activity retrieval via `StravaService`.
