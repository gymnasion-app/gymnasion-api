# Main Application Sources (`src/main`)

## Overview
Main production source and classpath resource tree (`src/main`) for the Gymnasion backend build.

## Subdirectories & Boundaries
- [java](./java/README.md) - Production Java 21 source code (`com.gymnasion.tcc`).
- [resources](./resources/README.md) - Application configuration properties, Flyway PostgreSQL migrations (`./resources/db/migration/README.md`), email templates, and PDF fonts.
